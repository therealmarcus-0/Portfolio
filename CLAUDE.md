# Portfolio Website

## Overview
Personal portfolio site for Marcus (GitHub: therealmarcus-0). Static site built with plain HTML, CSS, and JavaScript — no frameworks. Hosted on GitHub Pages at `therealmarcus-0.github.io`.

## Tech
- HTML/CSS/JS only
- No React, no backend, no database
- GitHub Pages for hosting

## Structure
```
portfolio/
  index.html    — Single-page site with all sections
  style.css     — All styling, responsive design, animations
  script.js     — Mobile menu, scroll effects, form handling
  images/       — Photos, screenshots, project assets
  CLAUDE.md     — This file
```

## Sections
1. Hero — Name, tagline, CTA buttons
2. About Me — Bio, interests, photo
3. Featured Project — St. Mark's School App (main project, preparing for beta)
4. Other Projects — Smaller builds (finance tracker, golf stats, workout logger)
5. Tech Services — Local web dev business idea
6. Contact — Form + GitHub/email/LinkedIn links

## Context
Marcus is a high school student at St. Mark's School. Interests: CS, app development, golf, fitness, finance/investing. Targeting top STEM colleges (MIT, etc). Building this portfolio to showcase real work and a local tech services business.

## Conventions
- Keep code simple and readable — Marcus is learning
- Comment non-obvious code so he can understand and edit it
- No over-engineering, no unnecessary abstractions
- Professional but natural tone — not corporate
